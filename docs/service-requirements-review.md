## Available review and qualification

Final code review found and addressed transient publication/job mismatch, racing startup ownership, captured-request/usage adapter defects, sidecar lifetime, missing sampled wait reasons and SQLite connection-opening exclusion. The final admission scope retries only native connection opening; direct queries retain immediate typed rejection, caller work remains single-invocation, and corruption/permissions stay terminal. Metadata waits never reset advancement clocks. Source/collection isolation, dependency direction, broker payload boundaries, artifact inventories and human DCO trailers were reviewed against all plan sections above.

Frozen Windows workspace tests report 1,333 passes/17 ignores; non-root Linux production tests pass 1,347/18 skips. Serial docs, formatting, Clippy, native extension (217/2 skips), Python (142/4 skips), 411-package license inventories, repository and whitespace checks pass. Exact pair 59 passes model/retrieval/load/large-corpus/document/storage/usage/fault/transition campaigns and five real editor-stage scenarios. Final container isolation/persistence and controlled tmpfs full-volume admission/recovery pass. [Qualification](service-cutover-qualification.md) records exact identities and limitations.

Local candidate gates are complete: strict VSIX packaging and all five actual installed-VSIX scenarios pass across seven private VS Code 1.143.1 windows. The exact artifact and receipt are recorded in [qualification](service-cutover-qualification.md). The separate test driver is explicitly discovered while AIRK resolves from the installed VSIX. No public release is implied.

## Checks requiring another execution environment

The available host does not establish native Mac qualification, minimum Windows/macOS versions, actual SSH/WSL/remote-editor behavior, low-memory/slower-disk hardware classes, or enforced EDR/TCC/noexec/SELinux/AppArmor policy. On October 25, 2026, the user confirmed that no Mac execution host is available. Native Mac login, upgrade, packaging and installed-target checks are recorded as unavailable, not passed. Physical device/cache power loss has not been simulated.

Published target promotion remains behind the plan's installed-platform/signing matrix. Existing publisher-declared license records for three upstream crates still need release review because their packages do not contain separate license texts; pinned declarations are preserved without inventing legal approval. These qualifications are not silently counted as passed.
