## Requirements

### Validation cadence adjustment

Following the user's request to reduce time spent on repeated checks, small fixes receive focused affected-test reruns, formatting and affected-crate lint checks before their item commit. Broad checks already passed for unchanged behavior are not repeated merely to obtain another all-green invocation. The complete matrix is retained at the P5 foundation and P12 final gates; platform-sensitive changes receive targeted platform checks earlier. Dependency notices regenerate when dependencies change and at final qualification; extension checks run when its implementation or helper contract changes. Safety, identity, quota, recovery and exact-location acceptance tests remain mandatory for changes affecting those contracts. Receipts identify the exact broad run and follow-up corrections rather than claiming an uninterrupted full pass. No feature scope or final qualification requirement is removed.
