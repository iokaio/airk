Prompt contract

COMPILER
  • 1. Objective
    Human-authored intent, constraints, scope.
  • 2. Evidence
    Bounded excerpts, locations, hashes, gaps.
  • 3. Task instructions
    Template-specific sequence and limitations.
  • 4. Deliverables
    Files changed, tests, report and citations.
  • 5. Completion gates
    Do not claim success without verification.

Handoff alternatives

Dispatch governance

The queue can prepare future prompts automatically. Sending them to Claude Code, Codex, Gemini CLI, or another agent requires a tested adapter and explicit permissions. This mockup does not launch subprocesses.

Job state machine

PROPOSAL
  1. Draft → Validating: schema, bindings and scope preflight
  2. Collecting → Compiled: exact AIRK publication, stable evidence
  3. Approval → Ready: human gate and handoff selection
  4. Dispatched → Running: optional external adapter only
  5. Review → Complete: verify artifacts, tests and outputs
Error paths: blocked, stale, canceled, failed, partial.

Determinism checks

  • Explicit collection binding and no cross-collection tool selection
  • Finite loops with max fan-out, payload, and wall-time limits
  • Exact publication tokens across compound retrieval
  • Unknown fields rejected; no silent fallback or hidden steps
  • Path allowlists and reproducible template versions
  • Source content treated as data, not runnable instructions
