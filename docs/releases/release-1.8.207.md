## Implemented source behavior

- Agent setup supplies one Rust-owned manual entry with its exact file, format
  and text for Claude Code, Codex and VS Code. Automatic editing retains the
  whole-file and recovery safety policy; typed refusals leave manual setup
  available. Regenerate the entry after a service port change.
- Tokenless reads retain explicit scope and TLS/Host/Origin protections. Open
  Workbench plans use the admitted named-index authority instead of requiring
  Project membership. Terse replies preserve the canonical scope/status rules;
  migrated harnesses exercise tokenless endpoints and explicit index scope.
- The shared request default is 8192 input tokens and 120 seconds, propagated
  through native work and clients without resetting the original budget.
  Transport allows five additional seconds for response handling. Focus keeps
  its static 512-token pair width. See the
  [runtime budget contract](../arbiter/runtime-budget-contract.md).
- Service and Agents present current state, retry/manual setup and separate
  Focus/Context controls. The twelve-destination rail uses distinct icons,
  a flat layout and accessible collapsed navigation.
- Additive native resource and terminal contracts preserve historical evidence
  and require new exact-input qualification. Unsupported terminal classes
  abstain without selecting a lower-scoring Read. Setup, source-watch and
  process-recovery corrections retain their owning scope and failure fences.

## Qualification limits

Scoped contract, regression and input-census results retain their exact source
identities and counts in the ledger. They are not a completed workspace,
transport, installed, platform or release gate. A packaged file is a candidate
until its applicable installed journeys pass; this record does not claim that
a qualified release has been installed. Provisional signed Windows EXE/native
ZIP and universal VSIX candidates have been produced under commit1933; their
exact hashes and live UI/transport checks are retained in the ledger. Rebuilt
metadata/title candidate and platform checks remain in progress.

Bundled MiniLM retains the selected original publisher weights. Optional Focus,
Context Compact and Context Large remain separate downloads and require their
own current-artifact quality, calibration, resource and composed evidence.
The [software-v2 data audit](../arbiter/software-v2-data-audit.md) records missing
software supervision and suitable human judgments. No new training gain or
terminal qualification is claimed. The terminal classes remain unavailable
without their own human-backed evidence. Earlier 2048-token/30-second results
and failed or consumed evaluation populations keep their historical identities.

Current Context source-policy changes require native regeneration of metadata
and private evaluation staging; old profiles or captures cannot be relabeled.
All three qualified optional profiles and the native publication capture remain
mandatory for a final-series catalog. Public availability, cross-platform
qualification and publication are separate outcomes. No public upload,
deployment, PR or release publication is authorized by this candidate record.
