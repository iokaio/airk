01 / Get AIRK

Your workspace.
Your platform.

Download the extension for the machine running your workspace. Each VSIX includes its matching native helper.

Install the extension

In VS Code, open the command palette and run Extensions: Install from VSIX. Select your download, then open a trusted workspace.

Installation guide ↗

Using SSH, WSL or a development container? Choose the package for the remote workspace host. AIRK requires desktop VS Code; browser-only workspaces cannot run its native helper.

02 / From files to context

A small tool.
A grounded workflow.

Keep the index on your machine, see what is covered, and give your agent a way back to the original material.

  1. 1

    Index your workspace

    Open a trusted project. Automatic setup registers the folder and starts indexing saved files. Review readiness and extraction failures in Explorer’s Management tabs.

  2. 2

    Open Workbench or connect an agent

    Use AIRK: Open Workbench to run /files and inspect a cited result. Or run AIRK: Connect Coding Agent, review its scoped configuration and enable AIRK in that client.

  3. 3

    Retrieve with a reference

    Your agent can search, inspect definitions and read document evidence. Results retain source paths, content hashes and original locations within a published index revision.

AIRK runs locally without a service account or API key. Your chosen agent controls whether it sends retrieved evidence to its model provider.

03 / More than source code

The context lives
across your files.

See formats and extraction limits ↗
Code & configuration
Native grammar profiles for Rust, Python, TypeScript, Go, C#, Swift and more. Structured adapters for JSON, YAML, TOML and other configuration formats.
Documents & decisions
Markdown, text-layer PDFs, DOCX and PPTX. Retrieve passages and evidence cues such as headings, dates, requirements and numeric bounds.
Tables & worksheets
DOCX tables and XLSX stored cells preserve row and cell locations. Spreadsheet formulas retain stored results; AIRK does not recalculate them.
