# Usage and savings

Activity › Usage reads the local usage report of the selected index through this window's AIRK session (`airkctl usage report`). Choose a supported period from 1 through 30 days and Refresh usage. The default is 7 days; larger ranges are refused by the native service. Reported values are local estimates, not billing data, and the complete native report stays available under Complete response for copying.

A failed read shows its native code; it is never shown as an empty report. Usage recording settings (mode, retention, import and clearing) are in AIRK Admin, Usage: choose Usage settings in AIRK Admin.
