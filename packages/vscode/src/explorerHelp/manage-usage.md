# Usage and savings

Open this section from the tabs across the top of Management. Everyday controls remain in the Indexing tab: Search mode, Updates and Evidence detail.

Management › Usage displays the local Usage & Savings report in this tab for the selected project. Calls are counted by client; searches you run in the Explorer are reported as the AIRK Explorer client, separately from coding agents.

## Limits

Usage records are local, content-free aggregates by default. Estimates describe counterfactual context, not provider tokens or billing.

## Report in this tab

Management Usage loads the selected project's Usage & Savings report directly in the tab. Choose 7 or 30 days, Refresh, and use the report's existing measurement, feedback, recording and price-assumption controls. Project or binding changes discard the old session; late results cannot replace the new project's report. Failed refreshes label the previous report and offer Retry.

The renderer and native accounting are shared with the standalone command. Export spreadsheet, Export summary and Open as JSON remain explicit actions. Import and clear-history confirmations remain in force. Token estimates compare returned context with complete cited files; they do not measure provider billing, time saved or completed-task value.
