# Usage and savings

Management › Usage opens the local Usage & Savings report for the selected project. Calls are counted by client; searches you run in the Explorer are reported as the AIRK Explorer client, separately from coding agents.

## Limits

Usage records are local, content-free aggregates by default. Estimates describe counterfactual context, not provider tokens or billing.
