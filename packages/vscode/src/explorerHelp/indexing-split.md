# Indexing - Split review and recovery

Splitting an index into an independent destination is reviewed, applied, recovered and canceled in Explorer’s Index library. In the Explorer, an index's details offer Split status, which reads a split by its operation ID and shows the complete native status. Recommendations that suggest a split link to that index in Explorer’s Index library.
