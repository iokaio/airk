# Indexing - Split review and recovery

Splitting an index into an independent destination is reviewed, applied, recovered and canceled in AIRK Admin. In the Explorer, an index's details offer Split status, which reads a split by its operation ID and shows the complete native status. Recommendations that suggest a split link to that index in AIRK Admin.

Choose Open AIRK Admin to open the admin pages. Choose where... picks In VS Code (the Simple Browser, with a single-use sign-in link kept only in memory) or In my browser; the choice is remembered in the airk.admin.openIn setting. If the VS Code browser reports a certificate problem, choose Open in my browser.
