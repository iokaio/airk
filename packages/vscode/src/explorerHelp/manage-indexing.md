# Index settings

The Indexing tab contains Search mode, Updates and Evidence detail. Use the Recovery tab for advanced settings and repair previews.

Search mode selects Text only or Text + semantic. Semantic enablement verifies/prepares the offline model, preserves a custom selection and requests source indexing followed by eligible semantic work. An older publication can still show disabled while setup waits. The saved setting, applied job and published coverage are separate observations.

Updates selects Automatic or Manual. Pause is temporary and preserves that preference. Change detail opens the evidence-detail picker: Agent Lean, Search Only, Rich Structure or Detailed. Supported structured evidence and semantic search are independent choices; richer detail cannot manufacture missing OCR or complete language understanding.

Advanced settings includes vector eligibility, extra roots, custom/bundled model selection, recording, extraction policy, scan limits and storage quotas. Changes use native guarded requests. Missing or uncertain prerequisite inspections are requested automatically. If a prerequisite stays queued past the preparation window, the UI explicitly says the setting was not submitted; repeat the choice once inspection finishes.
