# Indexing settings

Management › Indexing holds each project's controls: inspect, index now, pause or resume, automatic watching, restart the project worker, install the bundled model, and **Project settings…**.

Project settings opens the native settings picker: vector search, index detail, vector eligibility, extra source roots, custom or bundled models, usage recording, extraction policy, scan limits, shared storage quota, calibration and unregistering the project. Each change becomes a durable native job; source files are never changed.

Choose **Indexing choices explained** or **Document types and OCR** on this screen for purpose-based guidance. **Index detail** offers Agent Lean (agent_lean), Search Only (essential), Rich Structure (balanced) and Detailed (detailed), with descriptions. Vectors are configured independently. Role lenses never change these settings.

Start with representative source formats and the evidence the task needs. Requirements/table work needs supported facts, not only text; scans need explicit local OCR. More detail cannot create missing scanned text, recalculate spreadsheet formulas or resolve all language references. Check capabilities and representative file profiles, review changes, then observe the native job and published state before relying on them.

## Limits

Inspect a project before configuring it so the request binds its current settings. An uncertain configuration outcome is shown; inspect again before requesting another change.
