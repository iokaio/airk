# Indexing settings

Management › Indexing holds each project's controls: inspect, index now, pause or resume, automatic watching, restart the project worker, install the bundled model, and **Project settings…**.

Project settings opens the native settings picker: vector search, index detail, vector eligibility, extra source roots, custom or bundled models, usage recording, extraction policy, scan limits, shared storage quota, calibration and unregistering the project. Each change becomes a durable native job; source files are never changed.

## Limits

Inspect a project before configuring it so the request binds its current settings. An uncertain configuration outcome is shown; inspect again before requesting another change.
