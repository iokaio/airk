# Outline of the selected file

Code › Outline shows the indexed outline of the source file selected in the Explorer header. The target is retained per project and does not depend on an active text editor.

## Limits

The outline comes from the published index, not from unsaved editor changes.

## Choosing the file

Use Choose file in the Explorer header to select an open editor tab or browse another file in the project. Open a file in the editor, then return to Explorer; the target survives focus changes and is retained per project. A file from another open AIRK project identifies its project switch. Source links open beside Explorer. Refresh outline rereads indexed evidence for this target; no live buffer or file is indexed by selecting it.
