# Document facts

Documents › Facts lists requirements, decisions, design and architecture statements, dates, sections and table rows extracted from Markdown, PDF, Word, Excel and PowerPoint, with their original locations.

## Steps

1. Choose a kind chip.
2. Optionally filter by text or a path scope, then choose **Find facts**.
3. Use **Load more** to continue where AIRK returned a cursor.

## Limits

Facts are extraction candidates found by document cues. They are not verified requirements and say nothing about live code behavior.
