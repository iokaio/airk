# Choose evidence tools

Open **Search → Evidence tools** to choose a guided Code, Documents, Evidence,
Review or Strategies view. These are the existing workflows, not a generic tool
runner. The older Explore evidence drawer, command entries and deep links remain.

- **Code:** symbols, textual references and selected-source outline. Written
  references are not resolved cross-file bindings.
- **Documents:** facts with extraction limits and original page/slide/sheet locations.
- **Evidence:** Inspector, Check citations and Indexed changes. Preserve saved-source
  checks, publication/baseline identity, coverage and bounded continuation.
- **Review:** Git staged/worktree changes, bounded impact and test candidates.
  Candidate tests are not executed tests; semantic impact is not complete.
- **Strategies:** Library, Studio and Planner keep their source checks, manual
  handoffs, complete exports and explicit save/import/overwrite safeguards.

Use **Back to Evidence tools**, then **Continue** to return to the last guided
view. In the same window and authority, a direct hub visit retains that view's
inputs and complete result. Changing project/selection/trust invalidates retained
view custody. A reload can remember the inert route, not restore read authority.

The browser hub lists the same workflow names and Help next steps. Guided browser
migration is incomplete; editor-only Git, source opening and local save actions
are not simulated. The browser native read form remains available separately and
does not adopt a VS Code window's scope. Choosing a hub entry only navigates; it
never creates/indexes/deletes, executes a query or authorizes an operation.
