# This window

The trusted host may supply this window's canonical descriptor. If it is unavailable, window association controls remain gated; no identity is inferred from open folders. Read saved association is explicit and does not create metadata. Review Project IDs and optional index defaults, then preview and apply the exact native changes. Up to 32 unique Projects and 32 unique indexes are supported. Zero Projects is valid only with zero index defaults. Native validation requires defaults to belong to the selected Projects.

Saved associations are preferences. Saving or deleting one grants no source access, switches no evidence session and changes no agent configuration. Access-grant controls and new-index setup remain unavailable in this screen. Existing single-index connections retain their configured source scope.

Create, update and delete use the existing exact native preview, durable request and preview digests, shared control transport and receipt reconciliation. Stale window descriptors, catalog revisions, namespace, client or trust invalidate the review. Unknown outcomes are checked by native receipt only; apply is never replayed automatically. Complete details, copy and export preserve the native association response and outcome.

Index library and Projects offer bounded native metadata reads and reviewed metadata operations when the native catalog is active. Missing activation is a native failure, never an apparently empty library. Opening this screen does not register folders, create storage or grant access.
