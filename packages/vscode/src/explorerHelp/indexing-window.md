# This window

Read saved association explicitly requests this window's complete native administrative descriptor through the existing connected service. It does not connect or start a service, register an index, or create an association. The native response supplies the host identity. If the descriptor is unavailable, association actions remain gated; open folders never imply evidence permission. Review Project IDs and optional index defaults, then preview and apply the exact native changes. Up to 32 unique Projects and 32 unique indexes are supported. Zero Projects is valid only with zero index defaults. Native validation requires defaults to belong to the selected Projects.

Saved folders and workspace files use an opaque private key in VS Code workspace storage. Empty windows, and unsaved contexts without a workspace-file identity, use a transient per-window key. A new empty window or restart does not promise to restore the same association. No repository or workspace file is edited to store this key.

Saved associations are preferences. Saving or deleting one grants no source access, switches no evidence session and changes no agent configuration. Existing single-index connections retain their configured source scope.

Review a new access grant takes 1–32 explicit Project IDs and an optional 1–32 index subset. Blank index selection asks native to enumerate eligible memberships inside those selected Projects; it never means every index on the host. Every selected Project and explicit index must be covered or native refuses the whole draft. The native service supplies the exact grant identity, caller, memberships, source revisions and policy snapshot. The form does not construct those authority fields or infer them from saved preferences.

Preparing the draft issues no access. Review the complete native request and preview, then explicitly choose Persist reviewed grant. This persists the reviewed metadata; it does not activate a connection, issue a worker credential, change an agent configuration or switch the current evidence session. The last submitted native draft remains in complete details and exports, including unknown native fields. New-index setup is a separate reviewed flow in Index library.

Read grants lists a bounded native page. Inspect grant retains the complete grant/provenance wrapper. Preview revoke grant uses the inspected native identity and revision; applying requires the complete native delivery-fence receipt. Revocation never selects another grant automatically.

Use Grant for this window is a separate explicit action. Choose one index and 1–32 Project IDs covered by the inspected reviewed grant. The host reads the complete native grant and index at the current window descriptor's catalog revision, validates the selection, then exposes the exact native catalog-session selector to Workbench and the automatic MCP provider. An index can be outside the open folders. Prior scoped histories remain separate, and stale evidence callbacks are fenced even when the backing index is unchanged. Saved manual agent configurations retain their own connection and scope. Opening this screen, saving preferences or persisting a grant never performs Use Grant. Reloading requires a fresh explicit selection; an inert withdrawal record prevents automatic fallback to a broader legacy connection. No saved preference activates access.

Create, update and delete use the existing exact native preview, durable request and preview digests, shared control transport and receipt reconciliation. Stale window descriptors, catalog revisions, namespace, client or trust invalidate the review. Unknown outcomes are checked by native receipt only; apply is never replayed automatically. Complete details, copy and export preserve the native association response and outcome.

Authority-changing operations require the complete native fence wrapper, not metadata alone. Pending fence preparation stays unconfirmed. Full request, receipt and delivery-proof observations are retained without rewriting their native caller, including across restart. Crossed request, digest or captured-target identities refuse settlement. A later missing receipt does not discard an already retained native proof or authorize another apply.

Index library and Projects offer bounded native metadata reads and reviewed metadata operations when the native catalog is active. Missing activation is a native failure, never an apparently empty library. Opening this screen does not register folders, create storage or grant access.
