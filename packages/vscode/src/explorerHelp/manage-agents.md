# Agent connections

Management › Agents connects coding agents to AIRK Retrieval, the 16 read-only tools scoped to one project.

## Steps

1. **Connect a coding agent…** picks the agent and writes or shows its configuration.
2. **Check the AIRK MCP helper** starts the launcher and lists its tools.
3. Restart the agent session so it loads the connection.

## Limits

Helper verification proves the launcher works. Whether an agent loaded it is checked in that agent.
