# Support

AIRK is an early scaffold with no support SLA. Use [GitHub Issues](https://github.com/iokaio/airk/issues) for non-sensitive questions, defects and bounded feature proposals. Include the AIRK revision/version, OS and architecture, command/tool, expected behavior and a minimal fictional example.

State whether a result used current or indexed content. For extraction problems, include format, extraction method and parse status rather than private source. Do not upload `.airk/`, shared collection volumes or `temp/`.

Read the [format matrix](docs/formats.md), [MCP guide](docs/mcp.md), [operations](docs/operations.md) and [roadmap](docs/roadmap.md) before reporting an unsupported capability. Sensitive reports follow [SECURITY.md](SECURITY.md).
