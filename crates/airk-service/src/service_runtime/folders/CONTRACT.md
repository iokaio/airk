# Public folder listing

Owner: Service runtime. Retained `.airk/agent-edits` trees, including unknown
versions and transaction descendants, are never folder-picker inputs or output.
Check direct/starting locations before constructing breadcrumbs and discard
retained children before metadata projection, sorting and continuation selection.
Native canonical-name observations supplement the lexical reservation predicate.

Refuse through the existing `folder_not_readable` channel without including the
private path in the error. Preserve ordinary folders, hidden-folder controls and
legacy `.airk` assets outside retained edits. This is a read boundary, not archive
ownership, write eligibility, cleanup or installation authority.

The starting list presents native OS drive roots as opaque shortcuts. It applies
lexical reserved-path refusal but never opens or canonicalizes those roots;
disconnected/network drives cannot consume a control request's frame deadline
merely by appearing in the inventory. A displayed shortcut grants no source or
folder access. Home and installation-data shortcuts retain native canonical
privacy checks. Explicitly selecting any folder, including a drive root or
alias, retains the ordinary canonical reserved-path and ancestor/link checks.

Pure observer regressions prove that drive presentation makes no native folder
observation, Home/data still invoke their checks and preserve refusals, and
lexically private synthetic drive names refuse before observation. Real control
transport qualification remains separate and keeps its existing deadline.
