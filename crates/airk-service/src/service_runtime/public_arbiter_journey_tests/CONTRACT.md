# Public optional-model journey controller (test-only)

The ignored Service test is a typed native controller for a separately started,
explicitly owned same-user matched runtime. It cannot create an EvaluationOwner,
seed private profiles, relax admission or invent metadata sources. The runtime
version, both executable hashes, install manifest hash, actual Health process ID,
instance, user SID and service image must equal the caller's frozen identities.
Every control request is bound to that actual instance. Output is create-new in a
native-opened protected directory under repository artifacts.

The controller constructs existing Core ConfigureResources, ManagementRequest
and NativeOfflineImportRequest values in Rust. Focus selection comes from the
unchanged compiled catalog and must be advertised by actual product Status.
Enabled enrollment names exactly one immutable index. Its one original source
root and backing root must match an explicit canonical source supplied by the
fixture; catalog revision is rechecked. Context is never configured here.
Configure/disable/unenroll preserve exact selected profile and intended roster;
stale Configure deliberately uses an older observed revision and accepts only
an actual typed refusal, without retry. Offline Import keeps native original
path checks. Provision additionally requires separate explicit download consent.

Throughput with a 64 GiB explicit ceiling is fixture-only configuration, never
proof that memory fits. Record the actual ResourceSnapshot and native refusal,
pressure and reservation observations. Operations retain their original native
read/frame/work deadlines. There are no polling sleeps or refreshed timeouts.

The controller owns no service process or lease: it never claims cleanup from
Status, queue acceptance, a PID lookup or its own return. The harness that
started the real process retains its handle and ordinary lifecycle stop receipt;
actual process exit and native release/lease proof are separate required checks.
Unknown/refused operations retain a failed receipt. Private current Context
qualification remains a separate EvaluationOwner journey, not public admission.
