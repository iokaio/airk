# Combined native body and delivery sizing

Kernel owns composition and inert serializer sizing. Core owns the native
types, stage bindings and their canonical packet extractor. These helpers
grant no source access, model work, retry, allocation or current eligibility.

Baseline Context admission retains its existing one-Context-slot sentinel per
selected member. Default Context omits its stage field, preserving the old
sizing bytes. Separate conservative two-stage sizing reserves both Context and
Focus for every member, including the maximum 64 binding roster. Neither
sentinel is an observed scope or executable grant.

Optional Focus must not reduce a fitting disabled-stage body by unconditionally
charging that maximum roster. Once the actual child observes eligible Focus,
its original allocation must fit the complete source/receipt plus the exact
Focus binding row and a conservative comma. Kernel checks that cost before NN
and reserves it again in final combined-child packing. If it cannot fit, Focus
is not dispatched; actual charged receipts cannot be dropped to obtain a fit.
Standalone packets have no combined roster charge.

The frontend collects both stages through Core's typed packet extractor.
Actual Focus outer metadata remains excluded from the byte pool reclaimed for
another child. Body plus Focus metadata beyond the original allocation is a
nonreplayable delivery failure, not permission to enlarge native Resources or
reinterpret NN work. Existing Work and Resources byte meanings are unchanged.
Unknown Focus work holds the partition like unknown Context work.

`combined_frontend::answer::tests::`. These include exact byte boundaries,
