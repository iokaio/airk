# Native installed CUDA admission adapter

The adapter derives the optional runtime root from the actual native image
parent; manifest name is airk-cuda-runtime.json and provider DLLs are siblings.
It accepts no client/config-supplied mapping. Explicit root/manifest arguments
must equal those derived locations before the Retrieval bridge runs.

admit takes the actual Arc<ServiceLease>, original Instant deadline and an
already-entered existing native ServiceComputeScope. It starts no second
inference owner or service. Retrieval retains the real lease; fields/hashes or
an advisory Core decision never stand in for it. CPU paths do not call this
module and need no optional GPU DLLs. Absent compiled runtime approval, absent
final-placement export or absent native CUDA capability returns unavailable.

Retrieval's cuda/CONTRACT owns held file/ACL/PE/hash/driver/module custody,
compiled runtime source approval, same-core provider dispatch, device capacity,
actual synchronization and final-placement observations. The public path tuple
is descriptive data only. No installer/package/1.9 qualification is claimed;
actual same-build closure, native optional-dependency absence checks, model
numerics/resources, consent/fallback, lifecycle and transport gates remain.
