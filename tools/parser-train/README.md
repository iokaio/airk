# Workbench intent model

`python tools/parser-train/train.py` rebuilds the historical smoke classifier into ignored local model storage using the pinned development dependencies in `requirements.txt`. Training is offline and uses original fictional templates, identifiers and paths; it does not read the user's workspace, clone repositories or retain source text. Expanded synthetic examples are saved locally under ignored `target/parser-train/data/` as hash-named JSONL files, in actual training order. A content-addressed copy under ignored `.parser-train/` survives `cargo clean`. Earlier corpora are preserved. `python tools/parser-train/retention.py` also retains vocabulary, candidate models, reports and sample manifests, excluding clones, source samples and native index state. The manifest records the dataset path/hash/row count, seed, feature specification and exact asset digest. Python and Rust share feature goldens in `fixtures.json`.

The binary has a 96-byte little-endian header: eight magic bytes, four u32 specification/count fields, two i32 thresholds, the SHA-256 label-catalog digest and SHA-256 payload checksum. Its payload contains 65,536 × 13 signed int8 weights in bucket-major order and thirteen i32 biases. Features are deduplicated hashed word unigrams/bigrams, boundary-marked character 3–5 grams and three shape flags. FNV-1a hashes UTF-8 bytes into 65,536 buckets. Runtime accumulation uses i32 with bounded 4,096-byte input and stable label-index tie-breaking. There is no embedding layer or runtime training dependency.

The embedded local-review candidate is **not qualified for automatic intent execution**. Its exact asset identity and confirmation-only scope are in `manifest.json`; the initial 12,480-example smoke record remains in `manifest-smoke.json`. The first public-vocabulary campaign selected 20,000 training rows from a 40k pool; its results remain in [qualification.json](qualification.json) and [the initial record](qualification-initial.json). The broader-phrasing campaign subsequently trained with 40k supported requests and 8k explicit unsupported requests, including pinned public query data. Its retained 150-utterance accuracy improved from 91.33% to **97.33%**, with no wrong accepted classifications on that fixture, while curated rejection and supported ask-rate gates still fail. See [TRAINING.md](TRAINING.md) and [qualification-broader.json](qualification-broader.json). No model was enabled for automatic learned execution. Runtime predictions supply suggestions after deterministic parsing abstains; explicit commands, validated recipes and explicit agent plans provide executable behavior.

Use `harvest.py --acquire` for the pinned sparse public checkouts, then `harvest.py --extract target/debug/airk.exe --sample` with a CLI built using `cargo build -p airk-cli --features parser-training --locked`. The development-only `dump-vocab` command does native extraction without vectors; the normal CLI excludes that command. `qualify.py` generates and saves all splits, compares 10k/20k/40k models on validation, selects calibration thresholds and measures the frozen candidate. `--development-only` skips final fixtures; `--promote` refuses unless every gate passes. Fit dependencies are pinned in `requirements.txt` and excluded from the product. Reproduction uses the retained exact vocabulary, repository pins, templates, dependency versions and seed; a fresh native index may have a different publication identity, which is recorded rather than rewritten.

Before enabling learned automatic execution, review the separately authored labels, improve rejection and enforce the design's acceptance floors. Calibration prioritizes at least 99.5% accepted-intent precision over coverage and records a missed 10% ask-rate target instead of weakening thresholds. The safety fixture measures raw classifier acceptance, not actual executions: runtime remains suggestion-only. Keep clones, generated corpora and harvested vocabulary under ignored `target/parser-train/`, never in public artifacts. A promoted model requires a new asset/version identity and review of its manifest, attribution and shared goldens.

`python tools/parser-train/online.py` downloads only the pinned CodeSearchNet query resource and CLINC150 data with their licenses and READMEs. `online.lock.json` records exact revisions, URLs, attribution, sizes and SHA-256 hashes; reruns verify those pins. Downloads and licenses are retained locally under ignored `target/parser-train/online/` and `.parser-train/`. No upstream code corpus is downloaded. CoSQA was researched but not incorporated: its authors distinguish MIT implementation code from the dataset's Computational Use of Data Agreement.

`python tools/parser-train/broaden.py` fits the broader candidate and freezes a hash-named development report without evaluating the final fixtures. It groups original variants into phrase families, holds whole families out for validation/calibration, groups public search topics by normalized query, preserves CLINC's official train/validation/test separation, and excludes cross-split normalized duplicates and ambiguous self-description categories. Unsupported training targets are thirteen zeros: the runtime label catalog and feature format remain unchanged. `--evaluate PATH_TO_FROZEN_REPORT` evaluates the saved model without refitting or adjusting thresholds. The existing 150/repository/safety fixtures are regression measurements, not new blind tests. Run `python -m unittest discover -s tools/parser-train -p test_broaden.py -v` for split, calibration and rejection contracts.

The local-review asset is installed explicitly with `python tools/parser-train/install_review.py tools/parser-train/qualification-broader-v2.json --suggestions-only`. It checks measured accuracy, supported accepted precision and integrity, preserves the previous binary, and writes model-specific Python/Rust inference goldens. This installs an inert-proposal model for the initial VSIX review, not an automatically executing classifier. The native runner still requires an explicit plan submission after a learned proposal. `train.py` now saves smoke artifacts locally rather than replacing the reviewed product asset.
