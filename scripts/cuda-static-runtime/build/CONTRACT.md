# Parent rebuild source boundary

Historical executable bodies and patch/lock bytes remain attributable through
source-map.json. SPDX header transitions never rewrite recorded historical hashes.
The retained original code is source material, not an authorized fresh-run API.
Only rebuild.py is a supported command here, and it is read-only and fail-closed:
no subprocess, filesystem mutation, build or qualification claim is permitted.
A valid manifest proves only its structure and observed pinned input bytes.
No empty/fake fixture or historical deadline extension may manufacture readiness.
Fresh execution needs a separately reviewed manifest binding and ownership/guard
integration; legacy main programs must not be used to bypass that boundary.
