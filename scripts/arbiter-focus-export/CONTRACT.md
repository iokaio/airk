# Adapted Focus FP32 export contract

This maintained, metadata-and-bytes exporter accepts only the authenticated original Focus static512 FP32 graph (SHA256 19b20ad4e39e173f6da602094b9c1583726a65fa76742553f97ec6f0f58436a1), its complete external-data closure, the pinned publisher BF16 checkpoint, and an actual completed full-TRAIN merged F32 checkpoint with pinned training custody. It does not import Torch, ORT, the half exporter, or execute a model. The caller supplies its already admitted process/output custody, full source pins and one original absolute monotonic deadline; there is no renewed budget or execution permit here.

Both checkpoint headers must have the exact 310 original tensor keys/shapes: 28 layers of seven projections and four normalization vectors, plus embedding and final norm. LoRA keys, duplicate/extra/missing keys, aliases, overlaps, holes, escaping paths, nonfinite values and dtype mismatches refuse. Publisher BF16 storage is expanded to canonical little-endian FP32 by shifting its 16 bits left by 16, without floating arithmetic or tolerance. All 198 non-target merged tensors must be bit-identical to that expansion. Only the 112 direct q/k/v/o matrices may differ. Both checkpoints omit a separate tied head; original and merged configurations must retain tie_word_embeddings=true and the same architecture.

The exporter independently binds all 311 original ONNX initializers to publisher canonical FP32: all seven projection families use exact matrix transpose; named embedding/norm tensors bind directly; the two-column readout binds original embedding rows 2152 and 9693 in that order. Exactly one direct RHS MatMul use per projection/readout is required. Unknown roles, shared projection storage/uses, unexpected shapes and incomplete mappings refuse. Original non-target graph payloads remain byte-identical, including all 113 inline learned tensors, 86 external learned files, and the separate external Constant mask file. The 112 adapted matrices are written to one new external FP32 file with exact little-endian transposition, using at most one 16MiB matrix plus bounded chunks; the largest actual adapted matrix is 8MiB. The embedding is always streamed. Restoring only those 112 original external descriptors must recover the original ModelProto byte-for-byte. Nodes, attributes, edges, masks, rotary math, positions, output readout and the three Int64 [1,512] inputs / two Float32 logits ABI remain unchanged.

Every consumed source is an explicitly pinned, canonical, non-reparse, single-link regular file held through final verification. Source hashes/identities are checked before and after; all loops and final retention use the original caller deadline. Output is create-new; partial outputs and a failure record remain after failure. The path-free output file roster and per-tensor byte lineage describe an unqualified candidate only. An actual completed owning process receipt, fresh independent adapted references, native numerical/resource/placement checks and subsequent acceptance remain separate. Existing publisher reference scores are never relabeled as adapted expectations. No production F1/instruction choice, calibration availability or release catalog is changed.

The external TensorProto closure includes every graph initializer and every node attribute `t` and `tensors` entry. Nested graphs, functions and sparse tensors are unsupported by this closed-original exporter and refuse. Every external payload needs a unique tensor identity, fixed-width dtype, pinned canonical file, exact declared range, and complete non-overlapping file coverage. Missing, changed, escaping, overlapping or unbound storage refuses before output creation. Immutable Constant payloads are copied byte-for-byte; intentional mask negative infinity is preserved and is not subjected to the learned-weight finite check. All 199 original external files are authenticated; after replacing 112 attention files with the packed attention file, all 87 remaining original files (including the mask Constant) are copied and pinned in the output roster.
