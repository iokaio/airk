# Maintained CUDA execution helpers

These three files are byte-identical copies of the reviewed ownership helpers
previously executed from ignored campaign artifacts. Current CUDA metadata,
component and producer tooling loads these tracked copies. FP16 preparation
pins these paths in new plans. Original files and historical receipts remain unchanged.

- `reference_owned.py`: Windows suspended child, Job, retained HANDLE and bounded
  process settlement, including `run_windows_owned_training` and `image_proof`.
- `reference_parent_no_site_r2.py`: `suspended_authentication`, `settled` and
  associated deadline/identity checks. It imports the sibling worker.
- `reference_worker.py`: `windows_sid`, file authentication and shared numerical
  reference helpers. Model libraries import only inside called numerical operations.

Use the maintained caller's reviewed plan and entry point. The old standalone
CLIs in these copied files use historical `__file__`-relative paths and are not
supported relocated entry points. This migration neither invokes those CLIs nor
changes their bytes. Numerical execution still requires its own reviewed inputs;
import alone grants no authority. See [CONTRACT.md](CONTRACT.md) for source pins.
