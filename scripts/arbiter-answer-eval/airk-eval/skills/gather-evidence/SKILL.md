---
name: gather-evidence
description: Use AIRK Gather Context to locate the rule, implementation, and example for a change whose behavior spans files.
---

When a change depends on behavior defined across files, ask Gather Context for the rule that controls the behavior, where it is applied, and an existing example that exercises it. Compare the returned passages with those needs. If one is missing, use a targeted search or read to fill that gap before editing. When the request already identifies a sufficient local example, go directly there.
