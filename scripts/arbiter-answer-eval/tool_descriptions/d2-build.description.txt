Use for a task that needs evidence from several places, such as a change that spans implementation and tests, even when the task names a symbol; call again with narrower needs as you learn more. Pass the task text as task, and optionally needs, anchors, deliverable and known. Returns a short map: for each need, where it is answered and the best passages, and what was not found. A code_change or test deliverable, or stated needs, also gathers the project rules, how tests run and the build file, and lists any it does not find. Ranges listed without text can be read with read_indexed_range. For one definition use find_definition; for one known file, outline_file. response_mode=full returns the complete reply.
