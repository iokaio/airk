# Arbiter FP16 graph exporter

Integrating this exporter does not authorize selected graph conversion, weight reads, native/GPU execution, or qualification. Selected-model conversion remains held until the actual FP32 gate passes and the reviewed native G5 math/provider owner is available. The module has no executable entry point. Original source graphs and external files remain immutable; exports create a new directory and fail closed, retaining partial output on error.

## Sources and tensors

Only the authenticated original full-FP32 Focus static512 graph (19b20ad4...), Compact c79c6725..., and Large f8ba5d3e... are accepted. Plan 12.5.2 adds one Focus source: `focus1024fp32` (794fc0b2...), which is 19b20ad4 widened to static [1,1024] by `focus_widen.py` with the same static-shape edits that produced the weight8 static-1024 graph. Its learned bytes are the 19b20ad4 bytes, repacked into one sidecar pinned by the widen receipt. Its `weights.bin` equals the static-512 conversion byte for byte (f94f74a2...). The `focus1024` key pins the weight8 static-1024 graph a16fcaa1... only so that the census can report on it; the role census refuses it, because it is weight8 and not FP32. Focus W8 and failed GQA/Dense candidates are rejected. Context publisher checkpoints are BF16, losslessly expanded to FP32 by the authenticated original exporter; this is not publisher FP32 storage. Conversion starts from those authenticated logical FP32 arrays and must later be checked against an independent publisher decode. Every source external file requires an exact SHA/size pin. All initializers are counted and classified; unknown weights, biases, quantization, aliases/overlapping external ranges, functions, graph mutations and unexpected topology refuse. Norm scale weights and Focus two-row head remain FP32. All embeddings and seven learned projections per layer become binary16, round-to-nearest-even, with no clipping. NaN/Inf and finite overflow refuse. Every range and converted output is digested. Original small Constant tensor data are retained FP32, including the static Focus mask.

## Math boundaries and ABI

Projection/embedding storage and GEMM outputs are half. Casts restore FP32 before original residual, RMSNorm, Q/K norm, RoPE, SiLU, multiplication and readout nodes. Context candidate rows come from the SAME rounded half embedding and only the gathered rows become FP32; no full FP32 embedding duplicate. Focus original two-row FP32 head and both output logits remain exact. The external three-input Focus and six-input Context native ABIs and output declarations remain unchanged. Native compiler input validation remains mandatory; this graph does not invent a second compiler.

Replace only the reviewed original causal attention chains. Context uses half GroupQueryAttention, source scale bits, causal=1, do_rotary=0, empty past-key and past-value slots, and current all-live sequential positions. Focus repeats each KV head consecutively, uses half MultiHeadAttention causal=1, no bias/cache and packed mask [live,pad,512,pad,512]. Native Focus input remains a nonempty left-padded suffix with position_ids=0..511. Where replaces undefined padded query outputs with half zero BEFORE output projection/residual; multiplication by zero is forbidden. Whole reachable source causal masks disappear only because no consumer remains. Every retained source node is byte-identical except classified learned-weight consumers. Unknown attention topology refuses.

Each Context GroupQueryAttention keeps its attention result at output slot 0. It declares /airk_g5/attention/{layer}/present_key and /airk_g5/attention/{layer}/present_value at slots 1 and 2 for the pinned CUDA kernel. Both are private graph values without consumers. Context exposes only scores and does not carry state across calls. Focus keeps its single MultiHeadAttention output.

## Runtime and acceptance remain held

sdpa_kernel is a CUDA provider option, NOT an ONNX attribute. Native G5 must bind Context Flash-only=1 or Focus MEA-only=2, ORT_CUDA_GEMM_OPTIONS=2 before singleton creation, TF32 off, compute32F, and no reduced-precision reduction. SM86 only for this scientific path. Actual node/dtype/kernel observations must prove Flash or MEA; flags alone prove nothing. No within-call fallback or old profile retagging. New graph/profile/compiler/math identities and full external-data/ABI native admission are required.

Matching-recipe limits require finite scores and identical argmax. For Windows and Linux Context FP16 CUDA, this release requires maximum absolute raw-score error <=0.007 and mass error <=0.05. Focus retains raw error <=0.001 and mass error <=0.00001. The 0.07 Context development ceiling is tracked separately. The original-FP32 comparison requires finite scores and mass error <=0.05. Focus also requires original-FP32 raw error <=0.25 and identical argmax. For fresh Context FP16 runs, original-FP32 raw error and argmax are diagnostic and the accepted task-quality gate requires at least 98% of FP32's judged evidence success rate with the specified paired confidence bound. Historical results retain their frozen criteria. Independent Torch original and half recipes, full native tensor provenance, genuine process settlement, numerical/resources/placement and full Answer latency gates remain required. Literal controls qualify only exporter mechanics, never selected models or GPU execution.
[Accepted Context FP16 rule](../../docs/arbiter/final-plan.md#accepted-context-fp16-task-quality-qualification)

The selected original graphs have no learned projection bias. Unexpected learned bias refuses rather than silently converting an unreviewed add/broadcast boundary. The CLI authenticates the declared source pins and performs graph conversion only. The owning campaign or caller must satisfy the FP32 and native G5 preconditions before invoking it; the CLI does not enforce a native admission capability and cannot activate or qualify a native model. The library name export_after_owner_admission expresses this caller convention, not an admission check or evidence that native admission currently exists. Original source closure authentication precedes conversion and is repeated afterward; the caller owns the immutable input/process/identity fence and the single absolute deadline.

## Portable recipe

`recipe='portable'`, or `--recipe portable` on the CLI, converts the same authenticated sources with the same role census and writes byte-identical `weights.bin`. Only the graph differs. Each learned projection weight stays binary16 in storage and passes through one Cast to FP32 that feeds the original FP32 MatMul. The activation operand and the product stay FP32. Token and candidate rows are gathered from the half embedding and only the gathered rows are cast, as in the default recipe. Attention is the same replacement of the reviewed causal chains, with FP32 operands and an FP32 result written directly to the original sink value. Context uses GroupQueryAttention with the same attributes, empty past slots, private present outputs and no attention bias. Focus uses MultiHeadAttention with the packed mask and an FP32 zero for padded queries. No tensor in a portable graph is cast to binary16. The report names `recipe` and `arithmetic` and carries no CUDA kernel requirement. The default recipe's graph bytes and report are unchanged by this addition, and a control compares them with the named default.

The portable recipe serves the CPU provider and GPU providers that compute in FP32. Its reference is FP32 arithmetic on the binary16-rounded weights. A runtime may fold the weight casts at load, which leaves FP32 weights resident. A session keeps them resident in half by disabling `ConstantFolding` and `FuseFp16InitializerToFp32NodeTransformer`, and that choice belongs to the execution identity. The recipe authorizes no execution or qualification, and every held condition above applies to it. The [independent portable graph proof](../arbiter-fp16-reference/CONTRACT.md#portable-recipe-graph-proof) covers the graph structure of a Compact or Large portable export. No independent learned-byte comparison covers a portable candidate yet.

R2 independent-review correction: every learned source FP32 chunk is checked finite, including protected norm scales and the Focus readout head. Their bytes remain unchanged when finite. Authenticated original Constant masks are not learned weights and retain their exact source semantics. Frozen R1 and its passing controls remain preserved under their original identities.
