# Linux source transport and user-space provisioning

These programs transfer a frozen reviewed source tree between Windows and the Linux guest, inspect raw/Git/newline identity, acquire and verify user-local package/compiler tools, construct reviewed overlays, and prepare or observe owned static-ORT builds. The windows_script fields are Python, not PowerShell. Inputs include frozen manifests, source archives, signed package rosters, local caches and historical user identities. Outputs include private extraction/overlay trees, source custody and execution receipts. Historical UID1000 and host path literals are retained evidence, not authority to run as another account.

See the [root README](../README.md) for private prerequisites, current-execution restrictions, exact prefix/hash semantics and source-only verification. Run `python -B -S scripts/arbiter/source_rescue/embedded_history/test_identity.py`; never launch archived scripts as a verification step.
