# Selected-goal preparation

This operational preparation owner checks exact maintained source provenance for
CAL packets/capture/aggregation, independent reference certificates, raw Context
scores and selected A6 confirmation. It keeps the collector and A6 helper
versions separate. It does not execute the preserved research programs.

`closure.py` validates byte pins and reversible source-map transformations.
`prepare_packets.py` builds a review-only13-phase census packet from explicit
input references. Neither script imports model libraries or launches children.
Run pure controls with `python -B -S -m unittest discover -s
scripts/arbiter/evaluation/selected_goal -p "test_*.py"`.

Input source references and private corpus/capture/profile records must be
reviewed separately. Outputs are JSON on stdout; retain them only through the
verified-human output guard in a fresh private run directory. No packet from
this owner is an execution release, native protocol document or qualification.
The current controller/capture/raw/model adapters remain unimplemented.

The fixed `source-selections.json` selects26 exact role versions from four source
maps. `current-owner-map.json` proves the original goal_sources and eval_agent_smoke
helpers equal their maintained tools/retrieval-train owners byte-for-byte. CAL
and A6 native clients and JavaScript session children intentionally remain
distinct. This26-role anchor audit is not a complete runtime import closure:
dynamic Python/model/SDK imports and additional source dependencies still need
operational adapter review. Original LF or CRLF SPDX prefixes are removed only
when explicitly declared; no source-body newline normalization occurs.

Run `python -B -S scripts/arbiter/evaluation/selected_goal/replay_cal_population.py`
to authenticate the retained CAL corpus, rubric, 100 ordered scope IDs,
13 phase memberships and 753 source paragraph ranges against their byte pins.
The receipt identifies the historically partly exposed CAL population for a
fresh capture. Use `--census-only` for the ordered input to prepare_packets.py.
Redirect stdout to a fresh checked private path. Historical phases supply
membership only. The fresh service scope and owned capture are still required.

The [CAL service capture owner](cal_capture/README.md) implements the separate
Windows fixture, owned phase workers and SDK transport under its own contract.
