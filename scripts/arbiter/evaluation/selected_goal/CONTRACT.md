# Selected-goal preparation boundary

This owner audits selected CAL/certificate/raw-Context/A6 source closure and
prepares review metadata. It does not import archived implementations, start
processes, execute models, emit native DTOs or grant execution/qualification.
Historical sources remain immutable provenance, never operational commands.

Source resolution uses exact original paths and hashes from the four
authenticated maintained source maps in the order listed in
source-selections.json. Basename matching, version substitution, symlinks, hard
links, reparse points and inferred normalization are refused. Each maintained
body must equal its recorded original after removing only the declared SPDX
prefix. Source-map authentication is separate from current API compatibility.
Unresolved source roles, runtime modules, native inputs and owner-policy migration
remain explicit prerequisites. A source audit cannot report execution readiness.

A review packet binds an exact ordered100-ID census to thirteen phases (twelve
of eight, one of four). It binds source/corpus/rubric/task-policy/profile/native
image and process-owner inputs by complete bytes and SHA256, preserves opaque
Rust-emitted documents, and grants no release. No historical deadline, owner SHA,
selected profile or fixture lifetime transfers to a new execution. Actual process
controllers and resource releases require a later reviewed operational adapter.

JSON inputs are bounded, duplicate keys refused, read once while hashing and
parsed from those authenticated bytes. The CLI emits JSON to stdout only; the
caller owns any audited private output. Missing roles prevent packet preparation.
