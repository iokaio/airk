# Historical evaluation and orchestration source

This archive preserves 404 distinct authored source versions and maps 527 historical paths to maintained owners. Of 404 distinct copied sources, 134 remain byte-identical and 270 add only an SPDX comment prefix. Removing each recorded prefix recovers the exact original bytes, including line endings, original notices and historical constants. Existing maintained source owners are referenced through their own provenance maps instead of copied again. Three third-party publisher/dataset source snapshots remain excluded with evidence in the map. No weights, datasets, private examples, captured results or receipts are included. Synthetic regression strings remain implementation fixtures.

The archive is inspectable source, not an operational launch package. Original imports, paths, old account identifiers, resource profiles and seals express historical assumptions; none grants current execution authority. Do not run files here directly. A selected rerun needs a reviewed maintained adapter, matched private dependencies, human identity/output guards and fresh seals. Hashes in filenames distinguish genuinely different versions; they are not new experimental outcome identities.

Run source-only checks from the repository root:

```powershell
python -B -S scripts/arbiter/evaluation/research_history/test_source_identity.py
```

The test reads maintained source and map only; it does not import experiments, read datasets, create caches or execute processes. No numerical/model/build/quality qualification is claimed.
