This is the exact historical source anchor named by final-plan section 7. `run_composed.py` drives reviewed native argv and the actual I2 SDK controller under an external owned-process boundary; `session_controller.cjs` handles original sessions, asynchronous calls, cancellation and journal observation. `evidence_checks.py` checks full SearchResponse preservation, observed races and finite resource telemetry. `assemble_observations.py` authenticates artifact references while deliberately retaining incomplete verdicts; it cannot grant qualification. `test_evidence_checks.py` contains synthetic controls.

All five files add only a recorded first-line SPDX comment; stripping it recovers their exact original bytes. The sixth original sibling, `os_measurement.py`, shares its original body and SPDX-prefixed maintained identity with the existing [maintained OS observer](../composed_orchestration/os_measurement--c81d48c34df4.py) and is mapped there without another implementation copy. See [source-provenance.json](../source-provenance.json) for exact hashes.

Inputs are a freshly reviewed Rust-emitted execution plan, actual SDK JS dependencies, controller packet, native runtime pair, process observation, artifact references and external owned-process/resource enforcement. Outputs are private step observations, stdout/stderr captures, incomplete receipt mappings and driver closure. Python, Node.js, Windows process APIs and the original matching SDK/native interfaces are required. Protocol/receipt-shape/review/result JSON are intentionally excluded.

This preserved version is not a current operational launcher. Its original 30-second request/event bounds and old response assumptions predate the current 120-second contract; callers must adapt them from the owning native contract before use. The sibling OS observer must resolve from its maintained owner through that reviewed adapter. Do not run archived workers or reconstruct approval from historical constants. Fresh runs require same-human identity, audited private output parents and reviewed source/input/runtime seals. Original hashes and limits are unchanged; maintained hashes record the SPDX prefix.
