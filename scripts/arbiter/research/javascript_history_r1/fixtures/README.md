# Historical editor fixture implementation variants

The source-map preserves11 aliases of four tiny authored serviceExtension.js
test implementations, as inert .js.in source templates. These are fictional
editor extension lifecycle probes, not private indexed inputs or product code.
No runtime profile, model data or credentials are copied.

Current scripts/check-extension-update-editor.cjs exposes panel.open and local
visibility in its diagnostic arguments; these older variants expose only route
and hand off local visibility. Their exact generator version was not found in
reachable Git source, so the small implementation bodies are preserved instead
of claiming exact reproduction from the current generator.

Every map row binds original bytes and a reversible SPDX prefix. Related eight
fixture hashes were separately reproduced from maintained AST literals without
executing the generator or generated code. This is source preservation only.
