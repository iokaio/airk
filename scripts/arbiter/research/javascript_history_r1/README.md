# Historical standalone JavaScript sources

This family preserves unmatched editor test drivers and their test bodies, plus
the help-search preview script. They are AIRK-authored historical implementation
variants. Existing scripts/check-agent-install.cjs, check-native-editor.cjs,
check-installed-explorer.cjs and check-extension-update-editor.cjs own related
current driver generation; the retained files do not claim exact reconstruction
from the current templates.

The .js.in files are inert source templates. Old absolute paths, environment,
activation hooks and sibling imports describe historical runs, not a supported
fresh command. Do not execute them or install their test extensions. Future use
requires current reviewed owners, explicit private inputs and same-human guards.

source-map.json binds every original artifact path/hash to a maintained file.
Only a declared first-line Apache SPDX prefix may be added; removing it recovers
all original bytes. Unique contents share copies. No package bundle, vendor
source, corpus, model, token or runtime receipt is copied here. Syntax checking
is not execution, type checking or product qualification.

The maintained analyzer's capture_standalone.ps1 takes an exact reviewed private
analysis report/hash. Its default is read-only; -Write creates fresh copies and
map using the mandatory human/output guard. Originals and previous receipts are
preserved. Every output is owner-audited before consumption.

The separate source_policy/source-map.json preserves31 aliases of one historical
sourcePolicy.js implementation (b39d1a6a...). Its validatePolicyChangePreview
variant was not found in current or reachable Git source; related current
validators live in packages/vscode/src/indexingCatalog.ts. This module imports
only AIRK indexingCatalog/publications, contains no bundled vendor code, and is
retained as an inert historical template. The original55 driver/test/search
templates remain separately counted. Capture uses -SourcePolicySupplement.

The final family has60 unique inert templates across273 original paths:55
standalone driver/test/search versions (231 paths), one source-policy version
(31 paths), and four older editor fixture implementations (11 paths). These are
three separate standard maps, with no duplicate public map aliases. Related
compiled bundles remain under their canonical current/historical source owners
with explicit output/source-version gaps; they were not bulk-copied here.
