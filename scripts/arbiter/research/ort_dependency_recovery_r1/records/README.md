# Exact recovery records

Each JSON filename is the SHA-256 of its exact bytes. The record authenticates the complete upstream base and observed result, then describes ordered byte replacements using offsets, deletion hashes and canonical base64 inserts. Recover with the maintained analysis/upstream_ort/recovery.py owner and the exact archive member linked in ../source-recovery.json. No fuzzy matching or historical command execution is implied. These are compact observed dependency changes, not full vendor source copies or claims of AIRK authorship.
