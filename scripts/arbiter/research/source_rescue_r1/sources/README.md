# Retained authored source versions

The origin and version of every file are recorded in `../source-map.json`. Full SHA-256 filename prefixes distinguish exact versions. Original filenames and paths identify the particular experiment or platform campaign; `.rs.in` preserves unintegrated Rust without adding Cargo modules.

Of 654 distinct retained files, 428 retain exact historical bytes and 226 add only a declared SPDX license prefix. Stripping that literal prefix recovers every original byte; no newline or encoding normalization occurs. Old absolute paths, deadlines, source pins and sibling imports are evidence of their original execution context, not a safe fresh-run interface. No code in this folder is automatically executed by the rescue. Fresh use must move a reviewed behavior change into its actual owner, with a current contract and audited input/output/process limits. Private model weights, training examples, indexed documents and credentials are not included.

The current utility and `test_rescue.py` enforce SPDX-prefix inversion. `replay_r1.py.in` preserves the exact original helper that produced the 416 generated-output proofs; it is historical source, not a second executable owner. `generated-replay-before-spdx.json` preserves the original proof metadata; current proof changes only that helper location and records the relocation.

Known retained details: the ba6d-prefixed remote-runner.py embeds a base64 source/config transfer bundle (seven source/config files, including public-only signing identity); it is source packaging, not merely hashes. The 21007b-prefixed test_cuda_component_execution.py contains historical non-UTF8 source and is not runnable as supplied; this rescue preserves that defect instead of silently transcoding it.

Fresh-owner reconciliation added one explicit historical CPU transition test snapshot (`6decae70...--tests.rs.in`): its former tracked owner advanced during Clippy correction, so the older body now has its own exact source version. The package accounts for 1,222 paths: 806 relocated origins and 416 independently reproduced generated outputs. The original routing document remains unchanged; the map and utility declare the additional source explicitly.
