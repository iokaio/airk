# Historical native and client implementation variants

This folder preserves unmounted AIRK implementation drafts and before-edit snapshots that were absent from the current branch history and prior maintained rescue maps. Native variants cover kernel/index/store contracts, process ownership and recovery, IPC/CLI/MCP read parity, installer/service lifecycle, Arbiter execution and qualification harnesses. Client variants cover VS Code Explorer, Workbench, model/profile management, retirement and retry behavior. These are source research inputs, not current runtime owners.

Retained source files use inert .rs.in, .ts.in, .tsx.in and .css.in names. They are not Rust modules, TypeScript compilation units, or supported commands.
