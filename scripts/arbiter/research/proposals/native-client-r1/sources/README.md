# Preserved source templates

These are exact historical authored source bytes, deduplicated by SHA-256. See the [parent README](../README.md) and [source map](../rescue-map.json) for original paths, statuses, dependencies and verification. Digest-prefixed names are storage identities, not a runnable module layout. Rust `.rs.in` files are proposal templates outside the production module graph. Do not execute scripts or compile isolated snapshots in this directory. Restore reviewed sibling paths and fresh private output custody before any reproduction; no model data, weights or execution receipts are included.

Historical JavaScript without an SPDX header is also stored as .cjs.in/.mjs.in inert templates. This preserves original bytes without introducing executable headerless files; the source map records every rename.
