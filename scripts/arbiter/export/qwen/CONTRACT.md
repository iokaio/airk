# Qwen source ownership and relocation contract

Versioned Python implementation belongs here; private data and sealed historical executions remain in artifacts. The source provenance manifest binds original bytes to maintained bytes and declares each transformation. Never rewrite retained seals or infer a passed model run from a source move.

Focus reference resolves the repository from its tracked source location and reads the original authenticated publisher assets. Static512 and weight8 imports use maintained siblings; callers supply explicit private source and fresh output paths. Static512 also requires the separate reviewed case file. Output under the tracked source tree is refused before model execution. All original numerical checks, model revisions and receipt admission remain intact.

Context reference and export retain their explicit release/assets/output interface and maintained sibling reference. Historical preparation and owned launch scripts preserve old sealed source identities and are not supported as relocated launchers. A new owned run must review and pin the maintained dependency closure, explicit paths, runtime and same-user process/resource controls; this migration grants no model execution or release qualification.
