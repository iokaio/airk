# Private fixture provenance contract

This read-only projector classifies only the three retained bookbuilder copies selected by the frozen broad source inventory. Source role requires the pinned benchmark producer, input configurations, completed source-preservation/isolation summaries, and the explicit copy chain. Names alone are insufficient. Every current candidate is hashed and must match the frozen observation. Later copies must exactly match the first retained copy.

Current original identity and historical indexed identity are separate observations. A changed, absent or inaccessible original is never described as equal. Historical equality requires the native inventory source hash and size, the manifest inventory digest, and the matching external root. Generated AssemblyInfo files without an exact current or historical witness retain the explicit role-only identity gap approved for this retained copy chain. This does not authorize arbitrary role-only exclusions.

Inputs are bounded, duplicate-key JSON is refused, and aliases are refused. Evidence is rechecked before output. The projector emits metadata bundles on stdout, never source contents, and creates no files. Guard redirected stdout and materialize it only through the reviewed upstream_ort materializer with an exact bundle SHA and fresh artifacts destination. Groups contain at most 500 rows and each emitted metadata file is at most 16 MiB. Private receipts and payloads are never staged. These observations do not qualify products, rerun benchmarks, or prove unselected directories free of authored code.
