# Retired source duplicate cleanup

cleanup.py plans removal of an explicit reviewed list of obsolete authored source files whose exact bytes survive in committed maintained sources. It verifies raw Git identities, source-map pins, exact identity/SPDX inverses, consumer-review evidence and human-owned source/parent policies. It emits a metadata-only plan to stdout. apply.ps1 independently revalidates that plan, records immutable private proofs, and removes one literal file at a time. It is not an artifacts cache cleaner. Preserve data, models, receipts, vendor inputs and private indexed sources.

Read [the cleanup plan](../../../../docs/arbiter/source-cleanup.md) and CONTRACT.md. The apply implementation must not be executed until the root reviewer has reviewed the combined change and committed the rescue and consumer verification transitions. The user has already authorized that bounded outcome; this is an implementation review boundary, not a request for renewed permission.

The private request is airk.source-cleanup-request/1 with rescue_commit, source_maps:[{path,sha256,bytes}], consumer_review:{path,sha256,bytes}, and files:[{source,destination,source_map,source_sha256,source_bytes}]. Source maps must be explicitly allowlisted committed scripts/native source-map.json or source-provenance.json files. Consumer review fields are specified in CONTRACT.md. Unsupported formats or nonreversible adaptations remain deferred rather than guessed.

From the verified human shell, use `python -B -S scripts/arbiter/analysis/source_cleanup/cleanup.py plan --input artifacts/<request.json> --sha256 <request-SHA256> --bytes <request-length>`. Guard any private stdout destination before writing it and audit its owner afterward. Every plan requires the cleanup implementation itself to have been committed at rescue_commit; tests use pure injected data and require no cleanup inputs.

After the committed freeze and root review, the bounded apply entrypoint is `pwsh -NoProfile -File scripts/arbiter/analysis/source_cleanup/apply.ps1 -Manifest artifacts/<plan.json> -ManifestSha256 <plan-SHA256> -ManifestBytes <plan-length> -ReceiptDirectory D:/code/Github/airk/artifacts/<fresh-receipt-directory>`. The receipt directory must not exist and its parent must already pass the human guard. Run only with active writers stopped. Do not retry an interrupted batch unchanged: reconcile its explicit intent/outcome receipts and create a new reviewed plan for the remaining originals.

Run pure controls with `python -B -S -m unittest discover -s scripts/arbiter/analysis/source_cleanup -p 'test_*.py' -v`. No test invokes apply or deletes files. Public inverse tests and private custody audits serve different purposes; absence of a private original must never silently turn a custody audit into a pass.

Read-only source observations are batched through one verified human process, including thousands of selected paths without thousands of shell/CIM startups. Token, owner, ACL and byte checks remain per file. Apply likewise reuses its verified process identity while refreshing each file/parent policy. Planning checks all input pins again before emitting its result.

`custody.py` is the shared adapter used by the four preservation test families. Their default mode runs permanent inverse tests; `--audit-originals` instead audits every original path and emits a private metadata report. Optional removal evidence is an exact SHA/length-pinned `airk.source-cleanup-removal-roster/1` JSON with `files:[{source,result:{path,sha256,bytes}}]`. The result pin points to the immutable successful per-file apply receipt, which binds its pre-removal proof and committed replacement. An absent original without that complete chain fails. Keep custody reports private and guard any stdout destination.

`prepare_consumer_review.py` prepares a finite review packet from explicit `--family artifacts/<family>`, repeated `--map <path>=<SHA256>` inputs and `--custody <strict-audit-path>=<SHA256>`. It verifies declared historical authored roles and exact inverse bytes, inventories text references across scripts/crates/packages/.github/docs, records each searched file pin and every match/error, and emits only metadata. It never marks a source apply-ready: dynamic map consumers, historical capture adapters and the exact per-file deletion decision still need review. Its first bounded packet covers 1263 optimization-history originals, excluding active final-plan/model and private fixture roots.
