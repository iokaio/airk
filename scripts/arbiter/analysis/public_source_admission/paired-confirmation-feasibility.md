# Prospective paired evidence feasibility

The release plan requires a one-sided 95% lower confidence bound of at least zero for FP16 evidence success minus 0.98 times original-FP32 evidence success. Neither the overall contrast nor the 8,192-token stratum has been measured. This note uses aggregate source metadata and hypothetical binary outcomes. It specifies no new release threshold. ## Pair and evidence accounting

Freeze eligible request IDs, source components, case weights, exact corpus/menu order, accepted evidence alternatives and budgets before either arm's confirmation output is inspected. Blind adjudicators to arm and outputs when completing judgments. Apply the same frozen evidence rubric to both arms. Each arm succeeds if it delivers any one complete acceptable alternative. Keep publisher relevance, answer occurrence and issue links separate from complete acceptance judgments. Audit every screened exclusion by reason. Run the frozen request on both arms with the same input opportunity and original deadline. Preserve any precision-driven difference in subsequent actions or delivered evidence.

For each request record binary success from actually delivered evidence. An abstention with no acceptable evidence, a completed refusal with no delivery or a request that times out without delivery contributes zero on its arm. A partial delivery is scored by the frozen rubric under the applicable deadline. Missing telemetry, an unexecuted arm or an unresolved judgment leaves an unknown, with its weight retained. Report both arms' success and failure counts, four paired outcome cells, unknowns by arm, exclusions and denominators. As a missing-data sensitivity check, assign unknown FP16 success zero and unknown FP32 success one for the worst compatible contrast, reversing these assignments for the best. These are endpoints for the observed sample, before sampling uncertainty.

Define the 8,192 stratum prospectively from the frozen, common compiler/input census and the plan's long-context definition. A token limit or a synthetic tensor at width 8,192 is insufficient. Show screened cases, eligible cases, groups, arms reached, refusals and actual delivered-evidence outcomes separately. Differential requests reaching a Context forward in only one arm remain visible in the intention-to-compare denominator. Preserve the original shared budget and all stops.

## What the counts imply

Let `X` be FP16 request success and `Y` original-FP32 success. The paired values `X − 0.98Y` are 0.02 for joint success, 1 for an improvement, −0.98 for a regression and 0 for joint failure. Their weighted average is the target sample contrast. The paired variance depends directly on these four cell probabilities and on within-source dependence. A baseline percentage alone cannot determine power.

In the illustrative known-perfect-baseline, independent identical Bernoulli setting, observing all successes gives the exact one-sided lower bound `0.05^(1/n)`. It first reaches 0.98 at 149. With 123 equally weighted independent trials it is 0.97594. This calculation does not set a minimum for the paired release gate.

For a separate conservative illustration assume fixed weights `w_g` summing to one and independent source groups with arbitrary within-group dependence. Each group's mean paired contrast spans [−0.98, 1]. Hoeffding's bound subtracts `1.98 × sqrt(log(20) × sum(w_g²) / 2)` from the observed weighted contrast. Equal hypothetical weights at 123 groups give a half-width of 0.21850. All joint successes yield an inconclusive bound, whereas all improvements yield a positive bound. Even six independent equally weighted groups all improving give a positive bound of 0.01070. This extreme example shows why a group count alone cannot prove impossibility. Unequal group sizes increase the half-width under request weighting. This sensitivity calculation assumes independent sampling at the group level and does not cure provenance or selection bias. It has no standing as the production interval. [Hoeffding (1963), Theorem 2](https://doi.org/10.1080/01621459.1963.10500830)

## Before confirmation

Use disjoint judged development pairs and the proposed frozen group sizes to estimate the four cells and between-group variance, with the observed distribution of requests per group. Report sensitivity across plausible discordance, dependence and source-family mixes, including the long-context population. If an interval is proposed, check its one-sided coverage under boundary-null simulations with few or unequal groups, rare regressions and complete ties; a variance or resampling interval can collapse to zero width when every observed pair agrees. Freeze the sampling target, cluster map, weights, confidence procedure, sample size, unknown handling, consequential-regression and long-context criteria before confirmation. If sizing uses a power target, identify its owner and report the assumed effect and loss distribution. Reuse prior approved criteria wherever they already exist. Report unresolved inputs explicitly. No development variance, approved power target, complete eligible cluster roster or adequate 8,192 count has been established by this metadata analysis.
