# Prospective paired evidence feasibility

The release plan requires a one-sided 95% lower confidence bound of at least zero for FP16 evidence success minus 0.98 times original-FP32 evidence success. Neither the overall contrast nor the 8,192-token stratum has been measured. This note uses aggregate source metadata and hypothetical binary outcomes. It specifies no new release threshold. ## What the counts imply

Let `X` be FP16 request success and `Y` original-FP32 success. The paired values `X − 0.98Y` are 0.02 for joint success, 1 for an improvement, −0.98 for a regression and 0 for joint failure. Their weighted average is the target sample contrast. The paired variance depends directly on these four cell probabilities and on within-source dependence. A baseline percentage alone cannot determine power.

In the illustrative known-perfect-baseline, independent identical Bernoulli setting, observing all successes gives the exact one-sided lower bound `0.05^(1/n)`. It first reaches 0.98 at 149. With 123 equally weighted independent trials it is 0.97594. This calculation does not set a minimum for the paired release gate.

For a separate conservative illustration assume fixed weights `w_g` summing to one and independent source groups with arbitrary within-group dependence. Each group's mean paired contrast spans [−0.98, 1]. Hoeffding's bound subtracts `1.98 × sqrt(log(20) × sum(w_g²) / 2)` from the observed weighted contrast. Equal hypothetical weights at 123 groups give a half-width of 0.21850. All joint successes yield an inconclusive bound, whereas all improvements yield a positive bound. Even six independent equally weighted groups all improving give a positive bound of 0.01070. This extreme example shows why a group count alone cannot prove impossibility. Unequal group sizes increase the half-width under request weighting. This sensitivity calculation assumes independent sampling at the group level and does not cure provenance or selection bias. It has no standing as the production interval. [Hoeffding (1963), Theorem 2](https://doi.org/10.1080/01621459.1963.10500830)

## Reproducible coverage sensitivity

The exposed 15-request TechQA TRAIN roster has 12 native admissions with matching original compiler digests and widths on both profiles, one submitted budget stop, one unqualified capture and one unobserved request. The 12 measured admissions span 1,158–1,609 tokens. None reached 8,192. The retained first-13 reference census reports **zero paired delivered-task outcomes**. Publisher judgments and model scores do not supply the missing pair of delivered Answer results, so empirical discordance, cluster variance, power and a confirmation sample size remain unavailable. The outstanding requests remain in the census. Neither the synthetic 8,192 control nor these 12 short admissions establishes prevalence or eligibility across the confirmation population.

`paired_confidence.py` implements the existing Hoeffding sensitivity calculation. Pass a previously frozen request-to-cluster map and disjoint, rubric-scored development records to `sensitivity(roster, pairs)`. A missing row or unknown arm keeps its original request weight. The report includes all nine observed cells across success, failure and unknown states, sharp sample bounds and the one-sided lower bound for the worst compatible completion. Its guaranteed coverage requires independent groups with fixed sizes for the target weighted expectation; it allows arbitrary dependence inside each group. Coverage says nothing about whether a selected corpus represents future requests.

The simulation uses only the already exposed native TRAIN census and original metadata group sizes. For each planning view, one draw controls every request in a group. The balanced-discordance boundary assigns improvement (+1) probability 49/99 and regression (−0.98) probability 50/99, so the true contrast is zero. Dynamic programming enumerates the probability distribution of the request-weighted sum exactly. The simulated percentages provide a reproducibility check over 10,000 draws per scenario, seed 25793. Request-independent coverage in the final column uses the same radius with each request incorrectly treated as independent.

Under the rare-regression boundary, joint successes (+0.02) occur with probability 0.98 per independent group and regressions (−0.98) with probability 0.02. The group bounds cover zero on every possible sample in these four designs. A zero-variance interval collapsed to the observed mean would exclude zero whenever every group happened to show only joint successes. That event alone has probability 8.33%, 5.79%, 9.79% and 88.58% respectively. With deterministic joint failures, the true zero contrast is covered in all four designs. When one shared shock instead determines all groups' discordant outcomes, actual coverage of the cluster bound falls to 50/99 (50.51%) in every design. This counterexample quantifies the effect of unrecognized cross-group dependence.
