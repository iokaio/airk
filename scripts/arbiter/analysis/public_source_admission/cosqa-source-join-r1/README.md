# CoSQA and CodeSearchNet source join

download_python_train.py acquires the pinned CSN Python TRAIN input; join_python_train.py matches CoSQA labeled code literals to exact source rows. collect_repository_rights.py collects repository grant/source evidence. verify_original_sources.py authenticates original files; stage_public_sources variants prepare source copies. The launch_native_visibility variants and tests preserve the historical native ownership/admission protocol.

- [qasper-train-focus512-proposal-r1](qasper-train-focus512-proposal-r1/README.md): Prepare a TRAIN-only QASPER proposal from retained eligible papers.
- [source-rights-applicability-review-r1](source-rights-applicability-review-r1/README.md): Seal per-source rights applicability and unresolved provenance without granting training admission.

These are historical source recipes, preserved byte-for-byte except declared SPDX prefixes. Many execute filesystem/network work at import and bind old private paths; do not import or run them as relocated commands. A fresh adapter must supply guarded private input/output roots, reviewed source/runtime seals and the original admission checks. No network, model or historical native job ran during this capture.

The family-root source-provenance.json maps original and maintained SHA-256 values. Original evidence remains in artifacts. No corpus payloads, weights, credentials, labeled examples or source-evidence copies were included. Source preservation grants no rights, training, publication or product qualification.
