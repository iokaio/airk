# Compact development margins

Run `python -I -B -S scripts/arbiter/analysis/development_margins/census.py`
from the checked human shell and capture stdout in a fresh private campaign
receipt. The script verifies both frozen five-row FP32 fixture files and
reports every original-publisher top-two margin at the historical 0.020
and provisional 0.140 cutoffs. An absolute score perturbation of at most
0.070 can change the leading option only at a reference margin at most
0.140. These original FP32 observations screen for leads. Apply the same
test separately to the actual matching-recipe reference when available.

The source selection reads the retained original TRAIN question file and
the pinned split receipt. It retains every answerable request whose whole
ordered publication menu is disjoint from the publisher DEV document
closure. The output includes private request text, menu IDs and identity
hashes for later native compilation. Keep every row and refusal, inspect
near ties on development only, and record threshold decisions only once
an applicable exact-artifact rule exists. No model scoring occurs here.
Run the controls with `python -B -S scripts/arbiter/analysis/development_margins/test_census.py`.
