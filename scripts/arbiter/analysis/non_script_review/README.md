# Frozen non-script source review

classify.py narrows the frozen component-review lane to Rust, TypeScript, CSS and HTML. It verifies live source hashes against that inventory, reuses the maintained source-inventory migration verifier, and checks reachable Git blobs with only explicitly disclosed UTF-8 CRLF-to-LF normalization. It emits private metadata for unresolved families; names and extensions never prove authorship or safe exclusion.

Run `python -B -S scripts/arbiter/analysis/non_script_review/classify.py --delta artifacts/<frozen-delta.json>` from a verified human shell. Guard the private stdout destination and audit it afterward. No source is copied, imported or executed and no repository content is changed. A reachable blob is historical identity, not current caller or runtime qualification; per-commit/path provenance is required before claiming a precise historical owner. Remaining files need human review and separate authenticated input/generated evidence or maintained historical preservation.

The report separates HEAD reachability from other retained local refs and records the exact observed ref tips. A local archive ref alone is not portable branch-delivery evidence. This tool is a candidate review aid, not an authority to skip uncommitted implementation; selected archive-only variants are preserved under research/non_script_history_r3.

roles.py is a compact review of the frozen residual list. It recognizes whole documented synthetic fixture bodies or constrained generated source forms, and verifies actual emit/copy anchors in pinned maintained producers. It records raw source hashes and producer pins, preserving the distinction between a positive generated/private-input role and unproved exact historical execution/output identity. It never copies fixtures. Unrecognized rows remain explicit; names alone never suffice. Run `python -B -S scripts/arbiter/analysis/non_script_review/roles.py --residual artifacts/<frozen-residual.json>` in the verified shell, guarding stdout as above. Pure recognition/refusal controls run with `test_roles.py`.
