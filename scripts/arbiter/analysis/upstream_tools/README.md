# Upstream tool and private fixture source proofs

project_archives.py verifies filename-selected artifact code against exact members of retained VS Code, CMake and Ninja archives. archive-catalog.json pins the original ZIP/tar bytes and their retained publisher metadata or maintained tool lock. Every admitted file must match both the frozen inventory identity and archived member bytes. It also verifies relocated VS Code Git askpass helpers against the corresponding official archive members. Names select candidates; they never establish exclusion by themselves.

The tool is read-only: it streams and rehashes archives, reads source bytes without displaying them, rejects aliases/duplicate archive paths, executes no vendor code and makes no network requests. It emits metadata JSON to stdout. Run it from a verified human shell, e.g. `python -B -S scripts/arbiter/analysis/upstream_tools/project_archives.py --delta artifacts/<frozen-broad-delta.json>`. Guard any private output parent before redirecting stdout and audit created files before consumption. Keep full per-file rows and source paths in private receipts; public files contain only the compact recipe and archive identities.

A matching distribution file is an upstream input, not AIRK-authored implementation or a newly qualified tool. Changed, absent and unproven files remain explicit errors. Other candidates remain outside scope. Do not copy vendor code, browser credentials or indexed fixture payloads into the repository. Private fixture provenance is a separate projection; a directory name alone cannot exclude a source file.

project_browser.py verifies retained browser extension scripts against signed per-file SHA256 tree hashes, using publisher keys bound to extension IDs or the explicitly pinned observed Edge runtime key. browser-key-catalog.json records that limited local key provenance. It makes no fresh Authenticode, download or webstore-root trust claim. Run with the same `--delta` argument as the archive projector. Pure controls run with `python -B -S scripts/arbiter/analysis/upstream_tools/tests.py` and `python -B -S scripts/arbiter/analysis/upstream_tools/test_browser.py`; the RSA positive/mutation vector was independently signed with .NET and contains no private key. See CONTRACT.md for bounds and publication rules.

project_private_tools.py authenticates private Codex system-skill copies against the installed human profile and retained client-home logs, and reproduces two historical indexed test inputs from their exact committed writeFile literals. It reads the current routing list and emits private disposition metadata to stdout. These observations establish input roles and byte identity, not upstream release authentication or a successful client test. Historical literal text and full private paths remain only in the private receipt. It never copies these sources into the maintained tree. Bookbuilder indexed-workspace projections belong to the sibling private_fixture_inputs owner.

project_crates.py proves retained Rust registry source trees against exact local .crate members. crate-catalog.json binds rustix and rmcp dependency archives to reachable historical Cargo.lock blobs, including the older rustix version. It reuses project_archives.py for bounded reads, alias refusal, archive rosters and member hashes. Run `python -B -S scripts/arbiter/analysis/upstream_tools/project_crates.py --delta artifacts/<frozen-broad-delta.json>`; stdout is a private source-disposition receipt with explicit unmatched/modified errors. Run pure controls with `python -B -S scripts/arbiter/analysis/upstream_tools/test_crates.py`. This authenticates retained input provenance, not a fresh registry download or build.

node-catalog.json uses the same archive projector for the seven retained Node 24.15.0 Windows launcher/environment wrappers. The original ZIP is tied to its retained acquisition receipt checksum; actual wrapper bytes must equal exact ZIP members. This is retained-archive provenance, not fresh publisher authentication. Select it with `--catalog scripts/arbiter/analysis/upstream_tools/node-catalog.json`.

review_vendor_docs.py audits a frozen 755-path document subset and emits metadata only. It separates exact retained archive members from positive package/advisory/publisher/tokenizer roles, pins source and evidence bytes, and leaves the other 75 document inputs to their owner. Run with python -B -S from a verified human shell; guard and audit any private stdout receipt. No vendor source text, model execution, security verdict or whole-directory exclusion is produced.

project_cargo_generated.py inspects the finite Cargo-output rows from an explicitly SHA-pinned private role report. It authenticates retained registry archives against Cargo.lock and SQLite bindings against the locked upstream Git revision, compares flag/private-module literals, checks OID table roles and protobuf version declarations, and binds each file to retained Cargo OUT_DIR/output metadata. It never invokes Cargo, a compiler or an upstream generator. Use `--input <private-report> --input-sha256 <SHA256> --cargo-home <verified-human-Cargo-home>`. Whole observed literal/copy matches are recorded separately from role-only OID/version checks; no historical build execution or whole-directory exclusion is claimed. Pure controls: `python -B -S scripts/arbiter/analysis/upstream_tools/test_cargo_generated.py`. Retained target files, vendor inputs and build outputs remain untouched.
