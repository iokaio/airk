# Historical source preservation contract

Preserve each authored original body exactly, with an optional explicit SPDX
prefix. All source paths, original/maintained hashes, lengths and deduplicated
owners are recorded. No automatic import/execution/materialization is provided.
Historical root assumptions, pins and limits remain historical, not qualification
for a new host or source epoch. Private data/vendor corpus remains excluded.
Changes beyond SPDX require separate review, tests and fresh source identities.
